wallpapers.tugurio.cl

Fuente de wallpapers para la extensión Random Wallpaper de GNOME (ifl0w/RandomWallpaperGnome3).

Cómo agregarla

  1. Instala Random Wallpaper desde extensions.gnome.org o con el gestor de extensiones de tu distribución.
  2. Abre la configuración de la extensión y agrega una nueva fuente.
  3. Elige el tipo Generic JSON y completa:
Request URL
https://wallpapers.tugurio.cl/wallpapers.json
Image JSON Path
$[@random].url

El resto de los campos se puede dejar vacío. @random hace que la extensión elija un wallpaper distinto cada vez.

Formato del JSON

wallpapers.json es un arreglo de objetos, uno por imagen, con un solo campo url que apunta a la imagen en este mismo sitio:

[
  { "url": "https://wallpapers.tugurio.cl/20191020_140043.jpg" },
  { "url": "https://wallpapers.tugurio.cl/P1112992%282%29.jpg" },
  …
]

Sirve con cualquier programa que acepte una lista de URLs en JSON. Más detalles en la documentación de Generic JSON Source.
